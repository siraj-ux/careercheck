# Frontend rules
- Mobile-first, with a desktop counterpart for every key screen.
- Indigo is the primary colour (CTAs, selected states, progress). Orange is the
  accent for unlock and upsell. Red is for errors only.
- Pill buttons, outlined cards, chips, toggles, calm progress bars.
- Tone: calm, reassuring, non-judgemental, plain language.
- Personality results must never use good/bad colour coding.
- Every chart has a "view as table" alternative. Keyboard support on desktop.
- Every screen has designed empty, loading, error and offline states.
